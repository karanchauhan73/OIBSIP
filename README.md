# OIBSIP Web Development Internship

This repository contains my project submissions completed during the **Oasis Infobyte Internship Program (OIBSIP)**.

The projects were developed using HTML5, CSS3, and Vanilla JavaScript, focusing on frontend development, responsive design, DOM manipulation, form validation, localStorage, and basic authentication concepts.

## 📂 Projects

### 1. Calculator

A functional browser-based calculator supporting basic arithmetic operations, operator chaining, decimal values, error handling, and responsive CSS Grid layout.

**Technologies:** HTML5, CSS3, JavaScript

### 2. Tribute Page

A responsive tribute page dedicated to Dr. A.P.J. Abdul Kalam, featuring his biography, achievements, timeline, inspirational quote, and visually engaging design.

**Technologies:** HTML5, CSS3

### 3. To-Do Web App

An interactive task management application that allows users to add, edit, complete, and delete tasks. It includes pending and completed task lists, task counters, empty-state messages, and localStorage persistence.

**Technologies:** HTML5, CSS3, JavaScript

### 4. Login Authentication System

A client-side authentication system with user registration, password validation, duplicate user checking, login validation, protected dashboard access, logout functionality, and basic password hashing.

**Technologies:** HTML5, CSS3, JavaScript, localStorage

## 🛠️ Overall Skills Demonstrated
