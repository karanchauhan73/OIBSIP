# Calculator

A fully functional browser-based calculator developed as part of the OIBSIP Web Development Internship.

## 📌 Project Overview

This project is a user-friendly calculator application built using HTML5, CSS3, and Vanilla JavaScript. It performs basic arithmetic operations and provides a simple, responsive button-based interface.

The calculator was developed without using JavaScript's `eval()` function. Instead, the calculation logic is implemented using variables, conditional statements, and operator handling.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JavaScript)

## ✨ Features

* Display screen for current input and results
* Numeric buttons from 0 to 9
* Decimal point support
* Addition (+)
* Subtraction (−)
* Multiplication (×)
* Division (÷)
* Equals (=) button for evaluating expressions
* Clear (C) button to reset the calculator
* Backspace/Delete button to remove the last entered character
* Division-by-zero error handling
* Operator chaining for sequential calculations
* CSS Grid used for button layout
* Event listeners used for all button interactions
* No inline `onclick` attributes
* No use of JavaScript `eval()` function

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the `WebDev-L1-Calculator` folder.
3. Open the `index.html` file in any modern web browser.
4. Use the calculator buttons to perform arithmetic operations.
