# To-Do Web App

An interactive task management application that allows users to create, manage, edit, complete, and delete daily tasks.

## 📌 Project Overview

This project is a responsive To-Do Web App developed using HTML5, CSS3, and Vanilla JavaScript.

The application allows users to efficiently manage their daily tasks by organizing them into two separate sections: **Pending Tasks** and **Completed Tasks**.

Users can add new tasks, mark tasks as complete, edit task details, and permanently delete tasks. The application also provides task count indicators and friendly empty-state messages when there are no tasks in a particular list.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JavaScript)
* DOM Manipulation
* Browser Local Storage

## ✨ Features

* Add new tasks using an input field and Add Task button
* Newly added tasks appear immediately in the Pending Tasks list
* Mark tasks as complete
* Completed tasks automatically move to the Completed Tasks list
* Edit task text inline
* Delete tasks permanently
* Display pending task count
* Display completed task count
* Friendly empty-state messages
* Timestamp display for tasks
* Responsive and user-friendly interface

## 📝 How the Application Works

### 1. Add Task

The user enters a task in the input field and clicks the **Add Task** button.

The new task is immediately added to the **Pending Tasks** list.

### 2. Mark Task Complete

When the user clicks the **Mark Complete** toggle, the task is moved from the **Pending Tasks** list to the **Completed Tasks** list.

### 3. Edit Task

The user can click the **Edit** button to modify the task text directly.

### 4. Delete Task

The **Delete** button permanently removes the task from the application.

### 5. Task Counts

The application displays the number of tasks in each list:

```text
X Pending
Y Completed
```
## 📊 Task Organization

The application organizes tasks into two categories:

### Pending Tasks

Tasks that have been added but are not yet completed.

### Completed Tasks

Tasks that have been marked as completed.
